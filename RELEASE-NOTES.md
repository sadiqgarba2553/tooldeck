# Tooldeck 0.5.1 for Windows

Download **Tooldeck-Setup-0.5.1-x64.exe** for standalone installation, or install and update it through BlueCloud Launcher with **tooldeck-0.5.1-win-x64.zip**.

- **New logo.** The red squircle toolbox artwork now appears in the app header, browser icon, Windows app icon and installer. The same logo is used in BlueCloud Launcher and on the BlueCloud website.
- **Updated icon and packaging systems.** Windows builds use a generated ICO directly, and the app window uses the matching native icon. Generated icon intermediates stay out of the distributed app. App-owned release metadata and SHA-256 checksums verify the packages delivered by the launcher.
- **79 local tools.** PDF, image, video, audio, conversion and utility workspaces remain available in the searchable card library.
- **Bundled offline runtimes.** PDF fonts, OCR with English language data, QPDF and FFmpeg are included for supported local processing. Files stay on your device; conversion limits are explained in each workspace.
- **Existing data is retained.** App identifiers, profiles, settings and downloaded content are preserved. This update can be installed independently or through the launcher's verified update system.

Windows x64 alpha preview; installers remain unsigned. Corresponding source, app metadata and SHA-256 checksums are included.

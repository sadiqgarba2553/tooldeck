# Tooldeck 0.5.0 for Windows

Download **Tooldeck-Setup-0.5.0-x64.exe** for standalone installation, or use **tooldeck-0.5.0-win-x64.zip** with BlueCloud Launcher.

79 local PDF, image, video, audio, conversion and everyday utility tools.

Existing app identifiers, settings and downloaded content are retained. Windows x64 preview; installers are unsigned. Corresponding source, app metadata and SHA-256 checksums are included.
